# 检查与安装更新

客户端启动后会检查稳定版，也可以手动查看。更新会结束当前会话并重启客户端，请先保存远程桌面上正在处理的工作。

1. 打开左下角的 **设置**，选择 **关于**。
2. 点 **检查更新**。若有新版，点 **下载并更新**；已是当前版本时，不必重新安装。
3. 客户端会核对下载大小和 SHA-256，再应用更新。重启后可回到 **关于** 查看版本。

![设置中心关于页中的检查更新入口](/shots/windows-update.svg)

便携版会替换原来的 EXE。安装版和 ZIP 版通过安装程序更新；原先解压的 ZIP 目录不会自动删掉。当前 Windows 用户的连接设置和配对关系会保留。
