# 关闭远控与移除配对

临时不想让其他设备连进来，可以保留配对。若不再信任某台电脑，请直接移除它。

## 暂停所有可信设备的远控权限

在**被控端**打开 **我的设备**，取消勾选 **允许可信设备远控本机（无需逐次确认）**。当前传入的远控会话会结束，已配对设备仍保留在列表里。

## 移除一台设备

在同一页选中对方设备，点 **移除配对**。即使对方离线也可以移除。对方列表里可能还有旧记录，但不能再用它连接这台电脑。

![在设备列表选中电脑后移除配对](/shots/windows-trust-revocation.svg)

![移除后列表为空，状态栏提示需要重新配对](/shots/windows-trust-removed.svg)

以后如需恢复，请重新[配对两台电脑](./pair)。
