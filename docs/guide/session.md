# 操作与结束会话

> 图示来自 0.3.0，界面细节请以当前客户端为准。

连上后，控制端会打开独立窗口。点击远程画面，再用鼠标或键盘操作对方电脑。

## 调整画面

两端都使用原生客户端时，点工具栏中分辨率和帧率旁的下拉箭头，可以更改码率上限或目标帧率。兼容的被控端还支持选择自适应策略：**清晰优先**适合文字，**均衡**兼顾画面和帧率，**流畅优先**适合动态内容。控制端显示被控端确认的选择；旧版对端可能不支持切换策略。点 **全屏** 隐藏工具栏；按 `Ctrl + Alt + F11` 恢复。

## 断开连接

![远程窗口的画面设置、全屏与结束控制按钮；画面为测试图](/shots/windows-session.svg)

控制端点 **结束控制**，或关闭远程控制窗口。被控端可以点 **结束共享**，也可以用桌面上的浮动停止按钮断开。

**关闭主窗口不会退出客户端。** 它仍在 Windows 通知区域运行。要彻底退出，右键托盘图标，选 **退出**。使用邀请码建立的会话断开后，需要新码才能重连。
