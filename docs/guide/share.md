# 共享这台电脑

> 图示来自 0.3.0，界面细节请以当前客户端为准。

在**需要别人协助的电脑**上操作。对方连入后能看到整个主屏幕，也能使用键盘和鼠标。请先收好不想展示的内容。

1. 在侧栏打开 **远程协助**，切到 **共享本机**。
2. 保持默认的五分钟有效期，点 **创建邀请码**。把邀请码私下发给要帮你的人，不要把部署密钥一并发出。
3. 对方发出请求后，点 **同意并开始共享**。不是你等的人就点 **拒绝**。

![共享本机页上用于设置有效期和创建邀请码的位置](/shots/windows-host-share.svg)

**持码免本机确认** 会跳过第 3 步，首个成功使用该码的人即可控制本机。临时找人帮忙时，建议保留默认的本机确认。邀请码只能成功使用一次；过期后要创建新码。

把[用邀请码连接](./join)发给协助你的人。
