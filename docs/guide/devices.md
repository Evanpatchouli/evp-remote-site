# 连接已配对的电脑

> 图示来自 0.3.0，界面细节请以当前客户端为准。

在家中电脑上允许远控后，你可以用已配对的电脑连回来，不必每次找人确认。

1. 在**被控端**打开 **我的设备**，勾选 **允许可信设备远控本机（无需逐次确认）**。只在确实要被控制的电脑上开启。
2. 让这台电脑保持登录、解锁，接有可用显示器，并保持客户端运行。
3. 在**控制端**的设备列表选中在线目标，点 **连接选中设备**，或双击对应设备行。

![在被控端打开可信设备远控权限](/shots/windows-trusted-control.svg)

![在控制端选择在线设备和连接入口](/shots/windows-trust-revocation.svg)

列表显示在线表示客户端已连上信令服务器，不代表桌面已解锁。若刚锁过屏，请在目标电脑上解锁，等它重新上线，再发起连接。

## 整理设备列表

在 0.4.0 中，右键设备行可重命名、置顶、上移或下移设备，也可将鼠标移到设备行上点击图钉置顶。设备离线时也能整理；名称、置顶和顺序只保存在本机，重启后仍然有效。
