# 下载与首次设置

要操作另一台电脑，两台都要运行 Evp Remote。请先向提供服务的人索取信令服务器地址。创建邀请码或使用「我的设备」的一方还需要部署密钥。



## 打开客户端

安装版按提示安装后，从开始菜单打开 EVP Remote。如果拿到的是便携版，双击文件名以 portable.exe 结尾的程序即可。若是 ZIP 压缩包，请先完整解压，再运行 EvpRemote.exe。

## 填写连接设置

1. 点主窗口左下角的 设置，打开 连接设置。
2. 两台电脑填写同一个 wss:// 地址。需要部署密钥的一方在此填写；只用邀请码连接别人时，密钥可以留空。
3. 点 保存设置。这些设置会保存在当前 Windows 用户下，下次打开不用再填。



同一地址下，密钥留空会保留原来的值。要删除旧密钥，勾选 清除已保存的密钥 再保存。有会话或待处理的邀请时，请先结束再改设置。
